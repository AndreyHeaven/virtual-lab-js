# virtual-lab-js
Интерактивная виртуальная лаборатория с двумя учебными логическими играми: «Переливания» и «Перекладывания» (Ханойская башня), с настройкой условий, пошаговым логом и автоматической проверкой победы.

# Доклад о проекте

## Проблема
Тренировка алгоритмического мышления и понимания ограничений в классических задачах обычно дается в сухом теоретическом виде. Из-за этого пользователю сложно увидеть, как правила задачи работают на практике, где именно совершаются ошибки и как шаг за шагом строится решение.

## Цель
Разработать простой интерактивный веб-проект, который позволяет наглядно решать две логические задачи: «Переливания» и «Перекладывания» (вариант Ханойской башни), с возможностью настраивать условия, выполнять ходы и получать обратную связь о корректности действий.

## Задачи
1. Реализовать экран подготовки параметров задачи перед стартом игры.
2. Добавить валидацию входных данных (допустимые диапазоны, обязательные условия победы, корректность конфигурации).
3. Реализовать игровую механику для двух режимов:
    - переливание между бутылками с учетом вместимости;
    - перекладывание дисков между столбами с запретом класть больший диск на меньший.
4. Добавить пошаговый лог действий пользователя и индикацию текущего этапа.
5. Реализовать автоматическую проверку достижения победного состояния и вывод результата.
6. Обеспечить понятный интерфейс, который работает как на десктопе, так и на мобильных устройствах.

## Краткое описание
Проект выполнен как набор HTML-страниц на чистом JavaScript без внешних библиотек. В нем реализованы две самостоятельные игры: `Переливания.html` и `Перекладывания.html`, а также базовый шаблон `skeleton.html` для повторного использования структуры интерфейса.

Каждая игра состоит из двух этапов: «Подготовка» и «Игра». На этапе подготовки пользователь задает параметры (объемы/цели для бутылок или стартовую/целевую раскладку дисков по столбам), после чего система проверяет корректность конфигурации. В игровом этапе действия выполняются кликами по источнику и приемнику; интерфейс показывает статус хода, визуальное состояние объектов и журнал шагов.

При выполнении условий задачи система фиксирует победу, показывает итоговый экран и позволяет скопировать лог. Таким образом, проект решает учебную задачу: превращает абстрактные алгоритмические правила в наглядный и проверяемый интерактивный процесс.
